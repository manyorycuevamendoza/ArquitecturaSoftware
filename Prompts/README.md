# Prompts

Métodos reutilizables que salieron del Lab 4. Se leen en este orden.

| Archivo | Para qué |
| --- | --- |
| [casos-posibles.md](casos-posibles.md) | Enumerar todos los casos de un punto de decisión y llegar al diagrama. El método de seis pasos. |
| [estructura-diagramas.md](estructura-diagramas.md) | El prompt listo para pegar cuando hay que dibujar: guion primero, tres iteraciones, generado con script. |
| [requisitos-desde-el-usuario.md](requisitos-desde-el-usuario.md) | Corregir los requisitos después de tener los diagramas: alinearlos con el lienzo, declarar de qué usuario nacen y cubrir las preguntas de la sustentación. |

El orden importa. Los casos dan el rigor, el diagrama da la narrativa, y los
requisitos se corrigen al final contra lo que el diagrama terminó diciendo.
