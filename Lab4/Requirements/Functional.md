# Requerimientos funcionales

| ID | Requerimiento | Criterio de aceptación verificable | Responsable |
| --- | --- | --- | --- |
| FR-DIS-01 | La central deberá crear un paquete semanal por región, escuela, grado y curso. | El manifiesto contiene `packageId`, semana, destino, versión curricular, lista de archivos, hash SHA-256 y firma; no se publica sin esos campos. | Coordinadora de contenidos |
| FR-DIS-02 | La plataforma deberá preparar una copia física del paquete y registrar su cadena de custodia. | Al despachar se registra paquete, transportista, destino y fecha; al retorno se registra el mismo `packageId` y resultado de instalación. | Operador logístico |
| FR-DIS-03 | El administrador regional deberá importar el paquete al Nodo Escolar Local sin usar Internet. | Con la interfaz de importación y el medio conectado, el nodo verifica firma y hashes localmente; una validación fallida no publica ningún archivo a estudiantes. | Administrador regional |
| FR-DIS-04 | Docentes y estudiantes deberán consultar los materiales desde la LAN/Wi-Fi del Nodo Escolar Local. | Con la interfaz WAN desconectada, un cliente conectado a la red local abre el catálogo, una guía y una actividad del paquete vigente. | Nodo Escolar Local |
| FR-DIS-05 | El nodo deberá mostrar la semana y versión vigente y conservar la anterior hasta que la nueva importación sea válida. | Después de una importación exitosa, el catálogo muestra la nueva versión; si falla, continúa disponible la versión anterior sin mezcla de archivos. | Nodo Escolar Local |
| FR-DIS-06 | El sistema deberá guardar avances, incidencias y solicitudes docentes en un paquete de retorno. | Sin conectividad externa, Rosa crea un avance/incidencia y el nodo lo exporta asociado a `schoolId`, semana y versión de paquete. | Docente rural |
| FR-AI-01 | El docente deberá iniciar una solicitud de IA con un formulario intermedio, no con un cuadro libre obligatorio. | El formulario exige objetivo, grado, curso, tipo de recurso, duración y formato esperado; el texto libre es opcional y tiene límite visible. | Docente rural |
| FR-AI-02 | El AI Gateway deberá normalizar la solicitud en un archivo estructurado y eliminar datos redundantes ya presentes en el curso seleccionado. | La solicitud almacenada conserva campos, plantilla y versión curricular; el prompt final no repite el temario completo ni texto descartado. | Plataforma |
| FR-AI-03 | Antes de invocar el modelo, el AI Gateway deberá pedir aclaraciones específicas si falta información indispensable. | Si falta un campo crítico, devuelve como máximo tres preguntas concretas y no crea llamada al proveedor ni registro de tokens facturados. | Plataforma |
| FR-AI-04 | El AI Gateway deberá recuperar únicamente los fragmentos curriculares etiquetados como pertinentes. | Para una solicitud, el registro muestra IDs de fragmentos; el contexto inyectado no excede el límite configurado y no incluye documentos no seleccionados. | Plataforma |
| FR-AI-05 | El AI Gateway deberá aplicar una plantilla por tipo de recurso y límites de tokens de entrada y salida. | Cada llamada conserva `templateVersion`, presupuesto de entrada/salida y tokens reportados; exceder el presupuesto bloquea la llamada o solicita reducir el alcance. | Plataforma |
| FR-AI-06 | El sistema deberá reutilizar un resultado aprobado cuando la solicitud normalizada, versión curricular y plantilla sean equivalentes. | Una repetición equivalente devuelve el `generationId` existente y no invoca al proveedor. | Plataforma |
| FR-AI-07 | El sistema deberá registrar tokens de entrada, salida y costo estimado por solicitud, curso y escuela. | Toda llamada exitosa o fallida con consumo tiene `requestId`, modelo, tokens, costo, versión y fecha; las preguntas de aclaración tienen cero tokens externos. | Plataforma |
| FR-AI-08 | La coordinadora deberá ejecutar un reporte de reducción contra una línea base comparable. | Para el conjunto de prueba, el reporte calcula `(tokens_base - tokens_gateway) / tokens_base × 100`, identifica tareas no comparables y aprueba la meta solo si el resultado es ≥ 40%. | Coordinadora de contenidos |
